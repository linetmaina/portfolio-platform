# Portfolio Dashboard (React SPA)

## Description

This project is a Single Page Application (SPA) built with React that allows a creative agency to manage and showcase its projects. Users can add new projects, search through existing ones and view them in a clean, responsive interface.

## Features

* Component-based architecture
* Add new projects dynamically
* Search and filter projects
* Responsive design

## Technologies Used

* React (Vite)
* JavaScript (ES6)
* CSS

## Project Structure

* Components for UI separation
* Centralized state management in App.jsx

## Live link
https://linetmaina.github.io/portfolio-platform/

## How to Run

1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
